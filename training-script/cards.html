立つ姿勢のポイント

スライド9　約5分
  1. 正面から：頭が傾かない・あごを軽く引く
  2. 肩の高さ・腰の骨の高さがそろう／ひざとつま先が同じ向き／足は腰幅
  3. 横から：耳・肩・足のつけ根・ひざ・くるぶしが、ほぼ一直線
  4. 胸は張らず楽に呼吸／腰は反らない・丸めない／ひざはゆるめる／足の裏全体
  5. よければ2人組で見合う（2分）。自分で確かめるだけでもOK。体には触れない
まとめ：「これは目安です。無理に『気をつけ』をさせないでください」

簡単なチェック方法

スライド10　約6分
  1. 痛みのある方は見学でOK → 壁際へ移動
  2. 壁立ち：後頭部・肩・お尻・かかとがつくか（30秒）
  3. 「いい悪いではなく、姿勢のくせを知るチェックです」
  4. 太もも前：うつ伏せでかかとをお尻へ（30秒）。抵抗があれば壁に手をついて立って
  5. 「突っ張りませんか。それがオスグッド病に関わる筋肉です」
しめ：「あったらどうするか。お席に戻って、次のスライドでお話しします」

運動前の動的ストレッチ

スライド19　約4分
  1. 立って、手がぶつからない間隔に。痛みが出たら止めてOK
  2. 肩回し：前・後ろに、ひじで大きな円
  3. もも上げ：その場でリズムよく、ひざをおへその高さへ
  4. 足のつけ根回し：片足で立ち、ひざで円（ふらつく方は壁に手を）
  5. ランジ：前に一歩踏み出して戻る（ひざがつま先より前に出すぎない）
声かけ：「反動をつけすぎず、リズムよく、大きく」 各10回ほど

運動後の静的ストレッチ

スライド26　約4分
  1. 太もも前：かかとをお尻へ（オスグッドに関わる場所）
  2. 太もも裏：足を前に伸ばして座り、前へ倒す
  3. ふくらはぎ：壁を押し、後ろの足のかかとを床につけたまま
  4. 床に座れない方は、立ってできるものだけでOK
声かけ：「1か所20〜30秒。息を止めずに、気持ちよく」 終わったら「お席へどうぞ」

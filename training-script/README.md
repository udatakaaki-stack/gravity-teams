# 研修シナリオ台本（改訂版）

少年期に大切な 姿勢・休息・動き・視る力（スポーツ少年団 指導者向け研修 60分）の台本です。

- `研修シナリオ台本_改訂版.pdf` 印刷用の台本（A4・55ページ）。改訂箇所の一覧、スライド修正リスト、本番前の確認ポイントを含みます。
- `本番用_進行台本.pdf` 演台に置いて使う本番用（A4・10ページ）。キーワード行、経過時刻、めくるタイミングの案内付き。`python3 stage.py` で作り直せます。
- `cues.py` 本番用のキーワードと、めくってよい場面の設定。
- `content.py` 台本の本文データ。文章を直すときはここを編集します。
- `build.py` `python3 build.py` で時間の合計をチェックし、HTML と PDF を作り直します。
- `slides/` 元のスライドPDFから書き出したスライド画像。

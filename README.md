# TELL ALERT（テルアラート）

投手のテル（球種によって変わる癖）を、スマホで記録して「本当に当たるテルか」を確かめるためのアプリです。
試合中のベンチやスタンドで、片手で操作できるように作っています。

## 使い方の流れ

1. 投手を登録する（名前と投球腕だけでOK）
2. 「テル」タブで、気づいた癖を書く
   - 直球の時の見え方と、変化球の時の見え方を書く
   - 動画を撮って、コマ送りで参考画像を切り出せる
3. 「計測」タブで1球ごとに記録する
   - 投球前：見えたサイン（直球サイン／変化球サイン／見えず）をタップ
   - 投球後：実際の球種をタップ（これで1球記録）
4. 的中率が「有効」になったテルだけを打者に伝える（「記録」タブの共有メモをコピー）
5. 途中で当たらなくなったら、アプリが「警戒」「緊急」で知らせる（投手がテルを直した可能性）

## 判定の考え方

- 的中率は「いつも多い方の球種を張った場合」と比べて評価します。直球が7割の投手なら、ずっと直球を張っても7割当たるからです。
- 「有効」は、その基準より当たっていて、偶然でこの成績になる確率が5%未満のテルです。
- 記録が少ないうちは「データ不足」と表示します。最低球数は設定で変えられます（初期値8球）。
- 変化検知は、それまで7割以上当たっていたテルが、直近8球で5割以下になったら警戒を出します。偶然の外れでも出ることがあるので、目での確認と合わせて使ってください。

## オフラインで使うには

GitHub Pages などの https のURLで公開し、電波のある場所で一度開いてから、ホーム画面に追加してください。
以降は電波のない球場でも起動できます（AI機能を除く）。

データは端末の中だけに保存されます。機種変更やチーム内での共有は、設定の「バックアップを書き出す／読み込む」を使ってください。

## AI併用モード（任意）

設定でAnthropic APIキーを入れると、次の2つをAIに手伝ってもらえます。

- 直球のコマと変化球のコマを比べて、テル候補を挙げる
- 試合途中のコマが、登録時のテルと同じかどうかの下書き判定

AIの結果は「候補」や「下書き」です。必ず計測の記録で確かめてから使ってください。

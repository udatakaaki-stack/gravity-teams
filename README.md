# ダイエットサポートプログラム

このリポジトリには、2つのプログラムが入っています。

| プログラム | 開くファイル | 対象 |
| --- | --- | --- |
| ダイエットサポート | `index.html` | ダイエット指導（この README で説明） |
| トレーニングサポート | `training/index.html` | 運動・筋力・チームトレーニングの指導（説明は `training/README.md`） |
| AI食事コーチ | `meal-ai/`（Vercel に置いて使う） | 食事の写真から AI が栄養を推定するスマホ向けアプリ（説明は `meal-ai/README.md`） |

ダイエット指導をするコーチ・トレーナーのためのツールです。クライアントごとに期分化プランを作り、日ごとのコメントを自動で作成します。作ったコメントは LINE や SNS にそのまま貼り付けたり、共有したりできます。

## 使い方

1. `index.html` をブラウザで開きます（インストールやサーバーは不要です）。
2. 左の「＋ 新規」からクライアントを登録します。
3. お名前・目標体重・開始日・期間（1〜365日）・声かけのトーン・気になっていることを入力して「保存する」を押します。
4. 各タブで、プランの確認やコメントの作成をします。

## 主な機能

| タブ | できること |
| --- | --- |
| プロフィール | 体重に加えてウエスト・睡眠・歩数・気分・メモを記録できる。基本情報、目標、期間（1〜365日）、トーン、運動経験・場所、悩みの登録。BMI・基礎代謝の推定、無理な目標への注意表示、体重の記録とグラフ |
| 期分化プラン | 「プラン表を印刷・PDF保存」で、期ごとの目的・食事・運動・心の持ち方をまとめたA4の計画書をクライアントに渡せる。期間に合わせて「導入期・減量期・調整期（停滞期対策）・仕上げ期・定着期」に自動で分け、各期の目的、食事・運動・心の持ち方、コーチ向けのポイントを表示 |
| 今日のコメント | 何日目かを選ぶと、その方の名前・トーン・期・曜日・前回からの体重変化・悩みに合わせたコメントを作成。「別の言い回しにする」で文章を変更、手直しも可能 |
| 定型コメント | 13の場面（あいさつ、記録へのお礼、体重が増えた時、停滞期、食事・運動への返信、飲み会の前後、体調不良、久しぶりの連絡、節目のお祝い、事務連絡など）に分けた41の定型文。名前・日数・体重が自動で差し込まれる。自分の定型文の登録・編集・削除、「この方専用」の定型文、組み込み定型文の複製アレンジにも対応 |
| ラポール21日 | 信頼関係を築く3週間（1〜21日）のアファメーションメッセージ。1週目「安心と信頼」、2週目「承認と自信」、3週目「自立と未来」。毎日「今日の言葉」と返信しやすい「今日の質問」入り。LINE用とメール用（件名付き、メールアプリで開く）を切り替え、送信日の表示、21日分の一括表示・保存に対応。コーチ向けの各日のねらいと、返信が来た時の対応のポイントも表示。クライアントの「今の気持ち」（不安、落ち込み、焦り、疲れ、食べすぎて自分を責めているなど）と、体重記録から自動で判断する進み具合（順調、停滞、増加、目標間近、達成など）に合わせて、寄り添いの言葉と「今の〇〇さんへ」のアファメーションが加わる |
| カウンセリング | 初回面談のヒアリングシート（目的、生活リズム、食事、運動、これまでの経験、持病・服薬、不安なこと、声かけの好み、連絡の希望）。「プロフィールに反映」で目的・運動経験・場所・トーン・活動量・気になっていることが自動で入る。事前に送る質問文と、コーチ用の回答まとめも作れる |
| 返信アシスト | クライアントの返信を貼り付けると、言葉の手がかりから気持ち（自分を責めている、落ち込み、不安、焦り、疲れ、前向き）と話題（食べすぎ、停滞、増加、飲み会、生理、睡眠など13種）を読み取り、寄り添った返事の案を作る。読み取り結果はボタンで選び直せる。体調不良やつらい気持ちを示す言葉があれば、ダイエットの話より体と気持ちを優先した返事にする |
| 週の振り返り | 1週間の記録（体重、ウエスト、睡眠、歩数、気分、記録した日数）から、よかったこと、体重への言葉、来週の小さな目標（2つまで）を入れた振り返りメッセージを作る |
| 送信管理 | 各タブの「✓ 送信済みにする」で送信履歴を残す。全クライアントの今日の送信予定、ラポール21日の送り忘れ、送信履歴（本文の再コピー・削除）を確認できる |
| 食事の例 | 朝・昼・夕・間食ごとに、自炊・コンビニ・外食の組み合わせ例24件（カロリーの数字ではなく選び方の例）。気になっていることに合わせて3件を選んだ提案文を作り、手動で差し替えもできる |
| 一括生成 | 1週間分、今の期すべて、全日程などをまとめて作成し、コピーやテキスト保存 |
| 停滞期サポート | 14の場面（体重が動かない、生理前、外食続き、筋トレ後の増加、やる気が出ないなど）ごとに、考えられること、対処と克服のヒント、そのまま送れるメッセージを表示 |
| 運動ライブラリ | 自宅・ジム・屋外別の筋トレ、有酸素運動、ストレッチ。やり方、ポイント、注意点、その方に合った回数の目安 |
| 体のしくみと知識 | 1日の消費エネルギーの内訳、脂肪が燃えるまでの流れ（分解からβ酸化、二酸化炭素と水になるまで）、食事誘発性熱産生、体重を減らすためにできること、よくある誤解、出典。テーマを選ぶとクライアント向けの説明文ができ、そのまま送れる。そのほか 停滞期、たんぱく質、BMI、運動の目安、睡眠、安全上の注意 |

### コメントの形式

- LINE・個別メッセージ：あいさつ、体重への声かけ、期に合わせたメッセージ、今日のヒント、運動の提案、結びの言葉
- ひとこと：短めのメッセージ
- SNS投稿用：名前や体重などの個人情報を入れない一般向けの投稿文（ハッシュタグ付き）

共有ボタンは「コピー」「LINEで送る」「Xに投稿」と、対応している端末では「その他のアプリで共有」が使えます。文字数と X の上限（280）も表示します。

### 定型文の差し込み記号

定型文の本文に次の記号を書くと、選んでいるクライアントの情報に置き換わります。登録画面のボタンを押せば、カーソル位置に入ります。

| 記号 | 内容 |
| --- | --- |
| `{name}` | 名前＋敬称 |
| `{day}` `{total}` `{remain}` | 何日目、全日数、残り日数 |
| `{phase}` | 今の期 |
| `{current}` `{lost}` `{toGoal}` | 現在の体重、開始からの減少、目標までの差 |
| `{startWeight}` `{goalWeight}` | 開始体重、目標体重 |
| `{coach}` | 署名 |

体重の記録がまだない時など、値が分からない項目は「〇」になります。送る前に書き換えてください。

### 安全アラート

記録やカウンセリングの内容から、コーチに注意が必要な状態を画面上部に表示します。それぞれ、クライアントに送れる文面もコピーできます。

| 種類 | 表示する条件 |
| --- | --- |
| すぐ確認 | 直近14日の記録メモに、めまい・動悸・生理が止まったなどの体調不良や、つらい気持ちを示す言葉がある |
| 注意 | 1週間あたりの減少が1kgかつ体重の1％を超えている、現在や目標のBMIが18.5未満、直近7日で睡眠5時間未満が3回以上、落ち込み・不安の記録が3回以上 |
| 確認 | 持病・服薬・妊娠中などの申告がある、18歳未満 |

言葉による判定はキーワードの一致なので、見落としや誤判定があり得ます。最終的な判断は必ずコーチが行ってください。

## サンプルデータ

画面上部の「サンプルを追加」（または最初の画面の「サンプルデータで試す」）で、架空のクライアント「サンプル 花子」さん（停滞期に入った記録、カウンセリングの回答つき）を追加できます。各機能の動きをすぐに確認できます。

## データの保存

クライアント情報と登録した定型文は、ブラウザ内（localStorage）にだけ保存され、外部には送信されません。別の端末に移す時やバックアップには「データ書き出し」「データ読み込み」を使ってください。まだ一度も書き出していない時や、最後の書き出しから14日たった時は、画面上部にお知らせが出ます。画面上部の「トレーニング版へ」から、トレーニングサポートに移動できます。

## 開発者向け

```
npm test
```

- `js/data.js`：期の定義、文章テンプレート、ヒント、運動、停滞期の場面
- `js/engine.js`：期分化の計算、コメント生成、指標の計算
- `js/features.js`：返信アシスト、安全アラート、週の振り返り、食事の例、カウンセリングのデータと処理
- `js/app.js`：画面の操作
- `js/app-extras.js`：追加機能の画面

文章を追加したい時は `js/data.js` の配列に項目を足すだけで反映されます。`{name}`（名前と敬称）、`{day}`、`{total}`、`{remain}` などの差し込みが使えます。

## ご注意

表示される数値や情報は一般的な目安です。医療的な診断や治療に代わるものではありません。持病のある方、服薬中の方、妊娠中・授乳中の方、成長期の方は、必ず医師に相談してください。

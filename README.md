# gravity-teams

トレーニングや運動指導の現場で使うツール・アプリ・資料をまとめた場所です。
以前は作品ごとに別々のブランチ（作業の枝分かれ）に入っていたものを、ここに1つにまとめました。

## フォルダの地図

```
gravity-teams/
├─ README.md            この案内
├─ CLAUDE.md            ものづくりの方針（Claude が作業するときのルール）
├─ .claude/agents/      計画・実装・確認を分担する補助役の設定
├─ apps/                実際に使うアプリ
│   ├─ diet-support/    ダイエット・トレーニング指導のツール一式
│   └─ tell-alert/      投手のテル（癖）を記録して確かめるアプリ
├─ documents/           研修などの資料
│   └─ training-script/ 指導者向け研修の台本とスライド
└─ artifacts/           claude.ai で公開中のページの一覧（リンク集）
```

## 中身の説明

### apps/diet-support（ダイエット・トレーニング指導ツール）

コーチ・トレーナー向けのツールが4つ入っています。詳しくはフォルダ内の `README.md` を見てください。

| プログラム | 場所 | できること |
| --- | --- | --- |
| ダイエットサポート | `index.html` | クライアントごとの期分化プランと、毎日のコメント作成 |
| トレーニングサポート | `training/` | 運動・筋力・チームトレーニングの指導 |
| AI食事コーチ | `meal-ai/` | 食事の写真から AI が栄養を推定（Vercel に置いて使う） |
| コーチとクライアントをつなぐ | `connect/` | クライアントの記録がコーチに届き、メッセージでやり取り（Vercel に置いて使う） |

動作確認は、このフォルダで `npm test` を実行します（`connect/` と `meal-ai/` で先に `npm install` が必要です）。

### apps/tell-alert（TELL ALERT）

投手の癖（テル）をスマホで1球ずつ記録し、本当に当たるテルかを的中率で確かめるアプリです。`index.html` 1つで動きます。

### documents/training-script（研修シナリオ台本）

スポーツ少年団の指導者向け研修（60分）の台本です。印刷用の改訂版PDFと、演台に置く本番用PDFが入っています。

### artifacts（公開ページの一覧）

claude.ai で公開している 28 件のページを、テーマごとに並べたリンク集です。

## 元のブランチについて

まとめる前のブランチ（`claude/diet-support-program-il8pdl` など）はそのまま残してあります。作業の履歴もこちらに引き継いでいます。

# TELL ALERT（テルアラート）

投手のテル（球種によって変わる癖）を、スマホで記録して「本当に当たるテルか」を確かめるためのアプリです。
試合中のベンチやスタンドで、片手で操作できるように作っています。

## 使い方の流れ

1. 投手を登録する（名前と投球腕だけでOK）
2. 「テル」タブで、気づいた癖を書く
   - 直球の時の見え方と、変化球の時の見え方を書く
   - 動画を撮って、コマ送りで参考画像を切り出せる
3. 「計測」タブで1球ごとに記録する
   - 投球前：見えたサイン（直球サイン／変化球サイン／見えず）をタップ
   - 投球後：実際の球種をタップ（これで1球記録）
4. 的中率が「有効」になったテルだけを打者に伝える（「記録」タブの共有メモをコピー）
5. 途中で当たらなくなったら、アプリが「警戒」「緊急」で知らせる（投手がテルを直した可能性）

## 映像で比べる（映像タブ）

同じ位置から撮った1本の動画で、投球ごとに同じ局面のコマを切り出して比べます。

1. 動画を開き、コマ送りで「セット完了」「始動」などの局面に印を付け、球種を押して保存する（投球の数だけ繰り返す）
2. 直球と変化球が3球ずつ貯まると、次のことを自動で行う
   - 手ぶれを補正してコマを重ね、直球と変化球で差が大きい場所を赤く表示する
   - 画面をマス目に分け、1球ずつ抜いて当てる方法で、直球と変化球を見分けられるマス目を探す
   - 局面の印のすべての組み合わせで、動作の時間（コマ単位）の差を調べる
3. 見つかった範囲や時間は、そのまま観察項目に登録でき、試合中の計測で確かめられる

ちらつき比較（直球の平均と変化球の平均を交互に表示）や、切り出し中に前の投球のコマを薄く重ねる表示もあります。
調べる場所や組み合わせが多いほど偶然見分けられて見えるものが出やすいため、「有効」の基準はその数に応じて厳しくしています。
赤く出た場所がボールや打者・捕手など、投手の癖と関係のないものでないかは、必ず目で確かめてください。

## カウント・走者

計測画面でカウントと走者の有無を記録すると、状況ごとの球種の割合（記録タブの「配球の傾向」）を集計し、予測にも反映します。設定で切れます。

## 観察項目のリスト

テルを探すときは、まず候補を広く記録し、記録で絞り込みます。
「テル」タブの「リストから選ぶ」で、投球動作を6つの局面に分けた47項目から、気になるものをまとめて追加できます。

| 局面 | 主な項目 |
|---|---|
| 準備・サイン交換 | 首振り、プレートを踏む位置、グラブの中で握りを探る、サインを見る時間 など |
| セット・構え | グラブの高さ・角度・ふくらみ、手首の角度、握り替え、肘、アゴ・目線・口元、静止時間 など |
| 始動・足上げ | 足の高さ・勢い・ひざの向き、上体の傾き、グラブの位置、足上げの時間 など |
| テイクバック | 手を出すタイミング、握りの見え方、手首の向き、腕の引き方、肘の高さ など |
| トップからリリース | 腕の振り・角度、踏み出す位置・幅、体の開き、頭の傾き など |
| テンポ・間合い | 始動から着地の時間、始動からリリースの時間、投球間隔、クイック |

各項目は「立てる／寝かせる」のような2つの状態で記録します。どちらが直球のサインかは決めなくてよく、記録が貯まると自動で判断します。
このリストは「テルになる」と分かっている項目の一覧ではなく、目で見て分けられる点を並べた候補です。どれが球種と結びつくかは記録で確かめます。
候補を多く調べるほど偶然当たって見える項目が出やすいので、「有効」の基準は計測中の項目数に応じて厳しくしています。

## テルの記録のしかた（旧版で作った項目）

| 種類 | 例 | 計測画面での操作 |
|---|---|---|
| 形が違う | グラブが胸の前（直球）／へその前（変化球） | 見えた形のボタンを押す |
| 出たら分かる | アゴを引いたら変化球、グラブを少し斜めに動かしたら直球 | 「出た／出ない／見えず」を押す |
| 動作の速さ | 変化球の時はモーションが速くなる | ストップウォッチを始動と着地で2回タップ |

動作の速さは、直球と変化球を3球ずつ測ると、両方の平均の真ん中を境目にして自動で判定します。
的中率は「その球より前の記録」だけで決めた境目で計算するので、後から当てはめて良く見せることはありません。

## 判定の考え方

- 的中率は「いつも多い方の球種を張った場合」と比べて評価します。直球が7割の投手なら、ずっと直球を張っても7割当たるからです。
- 「有効」は、その基準より当たっていて、偶然でこの成績になる確率が5%未満のテルです。
- 記録が少ないうちは「データ不足」と表示します。最低球数は設定で変えられます（初期値8球）。
- 変化検知は、それまで7割以上当たっていたテルが、直近8球で5割以下になったら警戒を出します。偶然の外れでも出ることがあるので、目での確認と合わせて使ってください。

## オフラインで使うには

GitHub Pages などの https のURLで公開し、電波のある場所で一度開いてから、ホーム画面に追加してください。
以降は電波のない球場でも起動できます（AI機能を除く）。

データは端末の中だけに保存されます。機種変更やチーム内での共有は、設定の「バックアップを書き出す／読み込む」を使ってください。

## AI併用モード（任意）

設定でAnthropic APIキーを入れると、次の2つをAIに手伝ってもらえます。

- 直球のコマと変化球のコマを比べて、テル候補を挙げる
- 試合途中のコマが、登録時のテルと同じかどうかの下書き判定

AIの結果は「候補」や「下書き」です。必ず計測の記録で確かめてから使ってください。

## 日本語の表示について

漢字は日本と中国で同じ文字でも形が少し違うものがあります（例：直・角・骨）。
端末に日本語フォントが無かったり、言語設定が日本語以外だったりすると、中国語の形で表示されることがあります。
これを防ぐため、日本語フォント（Noto Sans CJK JP を、よく使う漢字とアプリの文字だけに絞ったもの）を同梱し、最優先で使っています。
同梱フォントに無い珍しい漢字は、端末の日本語フォントで表示されます。

画面の文字を変えたときは、次のチェックを実行してください。

```
python3 tools/check_japanese.py
```

絵文字のように端末によって化ける文字や、同梱フォントに無い文字が見つかると「NG」と表示されます。
フォントに文字を足すときは `tools/make_font_subset.sh` で作り直します。

## ファイル

- `index.html` アプリ本体（1ファイルで動きます）
- `sw.js` オフライン用
- `manifest.webmanifest`, `icon*.png`, `icon.svg` ホーム画面追加用
- `fonts/` 同梱の日本語フォントとライセンス（SIL Open Font License 1.1）
- `tools/` 日本語表示のチェック、フォント作成、共有ページ（claude.ai のアーティファクト）作成のスクリプト

## 共有ページ版

`python3 tools/build_artifact.py 出力先.html` で、claude.ai で表示・共有するためのページを作れます。
この版はサンプル投手（例のデータ）が最初から入っていて、使い方の検討や説明に使えます。
ただし、ファイルの保存、AI機能、オフラインでの起動は使えません。データはその端末のブラウザにだけ残ります。

最初の画面の「サンプルで試す」から、アプリ本体でも同じサンプルを入れられます。

# ダイエットサポートプログラム

ダイエット指導をするコーチ・トレーナーのためのツールです。クライアントごとに期分化プランを作り、日ごとのコメントを自動で作成します。作ったコメントは LINE や SNS にそのまま貼り付けたり、共有したりできます。

## 使い方

1. `index.html` をブラウザで開きます（インストールやサーバーは不要です）。
2. 左の「＋ 新規」からクライアントを登録します。
3. お名前・目標体重・開始日・期間（1〜365日）・声かけのトーン・気になっていることを入力して「保存する」を押します。
4. 各タブで、プランの確認やコメントの作成をします。

## 主な機能

| タブ | できること |
| --- | --- |
| プロフィール | 基本情報、目標、期間（1〜365日）、トーン、運動経験・場所、悩みの登録。BMI・基礎代謝の推定、無理な目標への注意表示、体重の記録とグラフ |
| 期分化プラン | 期間に合わせて「導入期・減量期・調整期（停滞期対策）・仕上げ期・定着期」に自動で分け、各期の目的、食事・運動・心の持ち方、コーチ向けのポイントを表示 |
| 今日のコメント | 何日目かを選ぶと、その方の名前・トーン・期・曜日・前回からの体重変化・悩みに合わせたコメントを作成。「別の言い回しにする」で文章を変更、手直しも可能 |
| 定型コメント | 13の場面（あいさつ、記録へのお礼、体重が増えた時、停滞期、食事・運動への返信、飲み会の前後、体調不良、久しぶりの連絡、節目のお祝い、事務連絡など）に分けた41の定型文。名前・日数・体重が自動で差し込まれる。自分の定型文の登録・編集・削除、「この方専用」の定型文、組み込み定型文の複製アレンジにも対応 |
| 一括生成 | 1週間分、今の期すべて、全日程などをまとめて作成し、コピーやテキスト保存 |
| 停滞期サポート | 14の場面（体重が動かない、生理前、外食続き、筋トレ後の増加、やる気が出ないなど）ごとに、考えられること、対処と克服のヒント、そのまま送れるメッセージを表示 |
| 運動ライブラリ | 自宅・ジム・屋外別の筋トレ、有酸素運動、ストレッチ。やり方、ポイント、注意点、その方に合った回数の目安 |
| 食事と体の知識 | 体重が減るしくみ、停滞期、たんぱく質、BMI、運動の目安、睡眠、安全上の注意 |

### コメントの形式

- LINE・個別メッセージ：あいさつ、体重への声かけ、期に合わせたメッセージ、今日のヒント、運動の提案、結びの言葉
- ひとこと：短めのメッセージ
- SNS投稿用：名前や体重などの個人情報を入れない一般向けの投稿文（ハッシュタグ付き）

共有ボタンは「コピー」「LINEで送る」「Xに投稿」と、対応している端末では「その他のアプリで共有」が使えます。文字数と X の上限（280）も表示します。

### 定型文の差し込み記号

定型文の本文に次の記号を書くと、選んでいるクライアントの情報に置き換わります。登録画面のボタンを押せば、カーソル位置に入ります。

| 記号 | 内容 |
| --- | --- |
| `{name}` | 名前＋敬称 |
| `{day}` `{total}` `{remain}` | 何日目、全日数、残り日数 |
| `{phase}` | 今の期 |
| `{current}` `{lost}` `{toGoal}` | 現在の体重、開始からの減少、目標までの差 |
| `{startWeight}` `{goalWeight}` | 開始体重、目標体重 |
| `{coach}` | 署名 |

体重の記録がまだない時など、値が分からない項目は「〇」になります。送る前に書き換えてください。

## データの保存

クライアント情報と登録した定型文は、ブラウザ内（localStorage）にだけ保存され、外部には送信されません。別の端末に移す時やバックアップには「データ書き出し」「データ読み込み」を使ってください。

## 開発者向け

```
npm test
```

- `js/data.js`：期の定義、文章テンプレート、ヒント、運動、停滞期の場面
- `js/engine.js`：期分化の計算、コメント生成、指標の計算
- `js/app.js`：画面の操作

文章を追加したい時は `js/data.js` の配列に項目を足すだけで反映されます。`{name}`（名前と敬称）、`{day}`、`{total}`、`{remain}` などの差し込みが使えます。

## ご注意

表示される数値や情報は一般的な目安です。医療的な診断や治療に代わるものではありません。持病のある方、服薬中の方、妊娠中・授乳中の方、成長期の方は、必ず医師に相談してください。

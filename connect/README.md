# コーチとクライアントをつなぐダイエットサポート

クライアントがスマホで記録した食事の写真・体重・気分・メモが、コーチのスマホに届きます。コーチは記録を見ながら、AI の下書きも使って、寄り添った返信を送れます。

## 使う人と画面

| 使う人 | 開くページ | できること |
| --- | --- | --- |
| クライアント | 招待リンク（`app.html#join=…`） | 食事の写真を撮ると AI が栄養を推定して記録、体重・睡眠・気分・メモの記録、今日のカロリー収支と栄養、AI のアドバイス、コーチとのメッセージ、これまでの記録とグラフ |
| コーチ | `coach.html` | パスワードでログイン、全クライアントの一覧（今日のカロリー、体重、気分、未読、気にかけたいこと）、クライアントの追加と招待リンクの発行、記録の詳細（写真、栄養、30日分）、メッセージ、AI による返信の下書き、よく使う文、プロフィールの編集、招待リンクの作り直し、削除 |

どちらも、スマホのホーム画面に追加するとアプリのように使えます。

## コーチの一覧で知らせること

| 種類 | 条件 |
| --- | --- |
| すぐ確認 | 直近3日の記録のメモに、めまい・動悸・吐き気・生理が止まった・死にたい などの言葉がある |
| 注意 | 最後の記録から3日以上たっている、気持ちが沈んだ記録が2日以上ある |
| 確認 | まだ記録がない、体重が1週間で1kg以上増えた（水分などの影響もあり得る） |

一覧は「すぐ確認」→「注意」→「未読あり」→「最近記録した人」の順に並びます。言葉による判定はキーワードの一致なので、見落としや誤判定があり得ます。

## しくみ

| 部分 | 内容 |
| --- | --- |
| 画面 | `public/`（ホーム画面に追加できる Web アプリ） |
| サーバー | `api/coach.js`、`api/client.js`、`api/health.js`（Vercel の関数） |
| 保存先 | Upstash Redis（本番）。手元では `.data/store.json` |
| AI | Claude API（`claude-opus-5-5`）。写真の解析、アドバイス、返信の下書き。回答は JSON スキーマで形を固定 |

### 安全のための設計

- コーチのログインは、Vercel に設定したパスワードで行います。15分間に10回まちがえると、しばらく受け付けません。ログインの状態は署名つきのトークン（30日有効）で管理します。
- クライアントは、コーチが発行した招待リンクで本人を確認します。リンクの中のコードは推測できない長さで、サーバーにはコードのハッシュだけを保存します。リンクはいつでも作り直せ、作り直すと古いリンクは使えなくなります。
- コーチ用メモは、クライアントには見えません。
- 写真は、解析のために Claude API へ送ったあと、240px の小さなサムネイルだけを保存します。
- AI の利用は、クライアント1人あたり1日40回までにしています（使いすぎの防止）。
- API キーはサーバーだけで使い、スマホには渡しません。

## Vercel に置く手順

1. Claude Console（Anthropic の開発者向け管理画面）で API キーを作ります。
2. Vercel で「Add New」→「Project」から、このリポジトリ（`gravity-teams`）を読み込み、次のように設定します。
   - Root Directory：`connect`
   - Framework Preset：Other
3. プロジェクトの「Storage」（または Marketplace）から Upstash の Redis を追加し、このプロジェクトにつなぎます。リージョンは東京（ap-northeast-1）を選べます。つなぐと、保存先の環境変数（`KV_REST_API_URL`、`KV_REST_API_TOKEN`）が自動で入ります。
4. Environment Variables に次を登録します。

   | 名前 | 内容 |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | 手順1で作った API キー |
   | `COACH_PASSWORD` | コーチがログインするパスワード（長く、推測されにくいもの） |
   | `SESSION_SECRET` | ログインの署名に使う、長いランダムな文字列（例：パスワード生成ツールで40文字以上） |
   | `CLAUDE_MODEL` | 任意。使うモデル（既定は `claude-opus-5-5`） |

5. 「Deploy」を押すと、`https://〇〇.vercel.app` のアドレスができます。
6. コーチは `https://〇〇.vercel.app/coach.html` を開いてログインし、クライアントを追加して、招待リンクを LINE などで本人に送ります。

Vercel は、リポジトリの既定のブランチ（main）を本番として公開します。このブランチのままだと「プレビュー」として公開されるので、本番にする時は main に統合してください。

## 手元で動かす

```bash
cd connect
npm install
npm run demo   # AI を使わないデモモード（コーチのパスワードは demo）
COACH_PASSWORD=好きなパスワード ANTHROPIC_API_KEY=sk-ant-... npm run dev   # 本物の AI を使う
```

`http://localhost:3000/coach.html` を開きます。手元では記録が `connect/.data/store.json` に保存されます。

## 今の版でできないこと

- 新しいメッセージが届いた時の、スマホへのプッシュ通知（画面を開いている間は1分ごとに確認します）
- 複数のコーチでの分担（コーチのアカウントは1つです）
- 記録の書き出し（CSV など）

## 個人情報について

クライアントの体重、食事、体調のメモなどは、健康に関わる大切な個人情報です。サービスとして使う前に、記録をどこに保存し、誰が見られるかをクライアントに説明し、同意を得てください。保存先（Upstash）と AI（Anthropic）の利用規約・プライバシーポリシーも確認してください。

## ご注意

表示される栄養の値は、写真からの推定です。実際の値とは異なることがあります。持病のある方、妊娠中・授乳中の方、成長期の方は、食事の調整について医師に相談してください。

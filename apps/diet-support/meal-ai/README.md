# AI食事コーチ

食事の写真をアップするだけで、AI（Claude）が料理名・量・エネルギー・たんぱく質・脂質・炭水化物・塩分を推定し、1日の収支と AI コーチのアドバイスを届けるスマホ向けアプリです。Vercel に置くと、スマホのホーム画面に追加してアプリのように使えます。

## できること

| 画面 | 内容 |
| --- | --- |
| ホーム | 今日の判定（あと何kcalか、目標を超えたか）、カロリー収支の円グラフ（摂取・目標・消費の目安・差）、今日の食事一覧、トレーナーに送るまとめ（コピー・LINE） |
| 栄養 | たんぱく質・脂質・炭水化物・塩分の目標に対する進み具合、AI コーチのアドバイス（今の時刻とまだ食べていない食事に合わせた提案） |
| 記録（＋） | カメラで撮る／写真を選ぶ → AI が解析 → 料理ごとの推定値を確認・修正して記録。写真なしの手入力にも対応 |
| 履歴 | 直近14日のカロリーのグラフ、体重の記録とグラフ、日ごとの記録 |
| プラン | 性別・年齢・身長・体重・目標体重・活動量・ペースから1日の目標を計算、データの書き出し・読み込み |

## 目標の計算方法

| 項目 | 計算 |
| --- | --- |
| 基礎代謝 | Mifflin-St Jeor 式による推定 |
| 消費の目安 | 基礎代謝 × 活動量の係数（1.2 / 1.375 / 1.55 / 1.725） |
| 目標エネルギー | 消費の目安から、ペースに合わせて 0 / 250 / 500kcal 控えめ。ただし基礎代謝を下回る場合は基礎代謝に合わせる |
| たんぱく質・脂質・炭水化物 | 目標エネルギーの 20% / 25% / 55%（日本人の食事摂取基準（2025年版）の目標量の範囲内） |
| 塩分 | 男性 7.5g未満、女性 6.5g未満（同基準の成人の目標量） |

## AI の使い方（技術的なこと）

- 写真はスマホの中で長い辺 1280px に縮めてから送ります（通信量と費用を抑えるため）。保存するのは 240px のサムネイルだけです。
- サーバー側（`api/` の Vercel 関数）から Claude API を呼び出します。API キーはサーバーにだけ置き、スマホには渡しません。
- モデルは `claude-opus-5-5`。環境変数 `CLAUDE_MODEL` で変更できます。
- 回答は JSON スキーマで形を固定しています（構造化出力 `output_config.format`）。合計値は AI に計算させず、料理ごとの値をサーバーで足し合わせています。
- 安全分類器が回答を控えた場合は、サーバー側で別のモデルに自動で切り替わる設定（`fallbacks: "default"`）を入れています。
- 記録はスマホのブラウザの中（localStorage）にだけ保存されます。

## Vercel に置く手順

1. Claude Console（Anthropic の開発者向けの管理画面）で API キーを作ります。
2. Vercel にログインし、「Add New」→「Project」から、このリポジトリ（`gravity-teams`）を読み込みます。
3. 設定画面で次のようにします。
   - Root Directory：`meal-ai`
   - Framework Preset：Other
4. Environment Variables に次を登録します。

   | 名前 | 内容 | 必須 |
   | --- | --- | --- |
   | `ANTHROPIC_API_KEY` | 手順1で作った API キー | 必須 |
   | `APP_PASSCODE` | 合言葉。設定すると、合言葉を入れた人だけが AI を使えます（API キーの使われすぎを防ぐため、設定をおすすめします） | 任意 |
   | `CLAUDE_MODEL` | 使うモデル（既定は `claude-opus-5-5`） | 任意 |

5. 「Deploy」を押すと、`https://〇〇.vercel.app` のアドレスができます。
6. スマホで開き、iPhone は Safari の「共有」→「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、アプリのように使えます。

Vercel は、リポジトリの既定のブランチ（main）を本番として公開します。このブランチのままだと「プレビュー」として公開されるので、本番にする時は main に統合してください。

## 手元で動かす

```bash
cd meal-ai
npm install
npm run demo   # API を使わないデモモード（サンプルの結果を表示）
ANTHROPIC_API_KEY=sk-ant-... npm run dev   # 本物の AI を使う
```

ブラウザで `http://localhost:3000` を開きます。

## 費用について

Claude API は使った分だけの従量課金です。`claude-opus-5-5` の料金は、入力 100万トークンあたり 4ドル、出力 100万トークンあたり 20ドルです。画像は「幅 × 高さ ÷ 750」トークンほどになるため、1280 × 960 の写真で約 1,600 トークンです。実際の費用は回答の長さで変わるので、最初に何回か使ってから Claude Console の使用量で確認してください。

## ご注意

表示される栄養の値は、写真からの推定です。実際の値とは異なることがあります。数字は記録の前後に修正できます。持病のある方、妊娠中・授乳中の方、成長期の方は、食事の調整について医師に相談してください。

おすすめの試し方

  1. コーチの画面で、はなこさんを開く
  2. 「停滞期サポート」や「AIで下書き」でメッセージを作って送る
  3. 右上の「お試し版・切り替え」からここに戻り、はなこさんとして開く
  4. 届いたメッセージを読み、返信や食事の記録をしてみる
  5. もう一度コーチに戻ると、返信と記録が届いています

お試し版でできないこと

写真の AI 解析とアドバイスは、写真の中身に関係なくサンプルの結果を表示します。本番では Claude API が写真と記録を読み取ります。別のスマホとはデータが共有されないため、コーチとクライアントの切り替えは同じスマホの中で行ってください。

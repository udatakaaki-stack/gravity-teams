# トレーニングサポートプログラム

運動指導者、パーソナルトレーナー、部活動やクラブチームの指導者のためのツールです。ダイエットサポートプログラムの仕組み（期分化、コメント自動生成、定型文、ラポール21日、共有）を、運動・筋力・チームトレーニング向けに作り直した別プログラムです。

## 使い方

1. `training/index.html` をブラウザで開きます（インストールやサーバーは不要です）。
2. チームで指導する場合は「＋ チーム」、個人を指導する場合は「＋ メンバー」から登録します。
3. チームに所属するメンバーは、チームの期分化プラン（開始日・期間・目標・試合日・練習曜日）に自動で合わせます。個人のプランに切り替えることもできます。

## チームの画面

| タブ | できること |
| --- | --- |
| チーム設定 | チーム名、競技、レベル、トーン、署名、目標、開始日、期間（1〜365日）、試合日、練習曜日、練習場所 |
| メンバーの状態 | 全員の最新のコンディション（睡眠・疲労・筋肉痛・気分・痛み）、7日間の練習負荷、急性：慢性負荷比、注意を一覧で確認 |
| チームへのメッセージ | その日の期・テーマ・メニュー・強度の目安・コンディション報告のお願いを入れた、グループLINE向けの文章（個人の名前や記録は入らない） |
| 全員の個別コメント | メンバー一人ひとりの記録に合わせた今日のコメントを一度に作成 |
| 期分化プラン | 期ごとの強度・回数・セット数・休息、回復週、試合日、印刷・PDF保存 |

## メンバーの画面

| タブ | できること |
| --- | --- |
| カウンセリング | 競技歴、目標、試合予定、練習状況、けがの経験、今の痛み、持病・服薬、睡眠、食事、緊張しやすさ、声かけの好みを聞き取る。「プロフィールに反映」で目標・経験・場所・トーン・気になっていることが入り、痛みや持病の申告は注意に表示 |
| プロフィール | 所属チーム、ポジション、年齢、体重、経験、目標、トーン、気になっていること |
| 記録 | コンディション（睡眠・疲労・筋肉痛・気分・痛み）、練習（時間・きつさRPE）、挙上記録（重さ・回数）。練習負荷のグラフ、自己ベスト（推定1RM）を自動計算 |
| 期分化プラン | 個人またはチームのプラン |
| 今日のコメント | コンディションへの声かけ、自己ベスト更新のお祝い、期のメッセージ、今日のメニュー、ヒント。痛みや強い疲労がある日は、自動で軽めのメニューに切り替え。練習のない曜日は休養日のメッセージ |
| 返信アシスト | 選手の返信から状態（けが・痛み、悔しい、不安、やる気が出ない、疲れ、前向き）と話題（痛み、試合の結果、自己ベスト、伸び悩み、緊張など12種）を読み取り、返事の案を作る。頭を打った、胸の痛みなどの言葉がある時は、練習の中止と受診をすすめる返事を優先 |
| 週の振り返り | 練習回数、睡眠、疲労、自己ベストをまとめ、来週の目標を提案 |
| 定型コメント | 練習前後、ほめる、励まし、試合前後、けが・痛み・復帰、頭を打った時、欠席、チーム連絡など30件。自分の定型文も登録できる |
| ラポール21日 | 指導者と選手の信頼関係を築く3週間のアファメーション。今の状態（疲れ、伸び悩み、試合が不安、けが、やる気が出ない）に合わせて言葉が変わる |
| 課題サポート | 伸び悩み、疲れが抜けない、けがが怖い、試合で緊張、筋肉痛、試合に出られないなど10の場面 |
| 食事・補食 | 朝食、練習の前後、体を大きくしたい時、試合の前日・当日、遠征先の食事と補食の例13件。悩みと試合の近さに合わせた提案文を作る（カロリーの数字は載せていない） |
| 種目ライブラリ | 筋力、パワー、持久・体力、体幹、可動性・ケアの30種目 |
| 送信履歴 | 各タブの「✓ 送信済みにする」で残した記録。チームの「メンバーの状態」に、今日の連絡状況（済み・未）として表示 |
| トレーニングの知識 | トレーニングの5原則、目的別の強度の目安、1RM、RPE、練習負荷、テーパー、栄養、水分、痛みとけが、出典 |

## 期分化

| 目標 | 期の流れ |
| --- | --- |
| 健康・体力づくり | 準備期 → 基礎期 → 強化期 → 維持期 |
| 持久力・スタミナ向上 | 準備期 → 基礎期 → 強化期 → 維持期（基礎期を長めに） |
| 筋肥大・体づくり | 準備期 → 基礎期 → 強化期（長め）→ 筋力期 |
| 筋力向上 | 準備期 → 基礎期 → 強化期 → 筋力期 → 維持期 |
| 競技力向上 | 準備期 → 基礎期 → 強化期 → 筋力期 → パワー期 → 試合期。試合日を入れると、試合日に試合期が終わり、その後は移行期（積極的休養） |

強度・回数・セット数・休息の目安は、NSCA（全米ストレングス＆コンディショニング協会）の目的別の指針に基づいています。負荷を上げる期（基礎期・強化期・筋力期・パワー期）では、4週ごとに回復週（練習量を減らす週）を入れています。

## 計算方法

| 項目 | 計算 |
| --- | --- |
| 推定1RM | Epley式：重さ ×（1 ＋ 回数 ÷ 30）。10回以下の記録のみ |
| 練習負荷 | きつさ（RPE 0〜10）× 練習時間（分）。Fosterらのセッション RPE 法 |
| 単調さ（モノトニー） | 1週間の毎日の練習負荷の平均 ÷ 標準偏差。練習が週3日以上ある場合のみ |
| 急性：慢性負荷比（ACWR） | 直近7日の負荷 ÷（直近28日の負荷 ÷ 4）。練習記録が21日以上ある場合のみ |

ACWR がけがの予測にどこまで役立つかは、研究者の間でも議論があります。数字だけで判断せず、本人の様子と合わせて見てください。

## 注意の表示

| 種類 | 表示する条件 |
| --- | --- |
| すぐ確認 | 直近3日の記録に、頭を打った、胸の痛み、動悸、息苦しさ、しびれ、腫れ、めまいなどの言葉がある（頭を打った場合は脳しんとうへの対応も表示） |
| 注意 | 痛み・違和感の記録、疲労4以上や筋肉痛4以上が続く、睡眠6時間未満が週3回以上、ACWRが1.5超 |
| 確認 | 練習の単調さが2.0超、18歳未満 |

言葉による判定はキーワードの一致なので、見落としや誤判定があり得ます。最終的な判断は必ず指導者が行ってください。

## サンプルデータ

画面上部の「サンプルを追加」（または最初の画面の「サンプルデータで試す」）で、架空のチーム「サンプル高校 陸上部」と選手3人（4週間分の記録つき）を追加できます。注意の表示や、自己ベストの更新、練習負荷の計算などをすぐに確認できます。サンプルのチームを削除すると、サンプルの選手も一緒に削除されます。

## データの保存

データはブラウザ内（localStorage）にだけ保存され、外部には送信されません。ダイエット版とは別に保存されます。別の端末に移す時やバックアップには「データ書き出し」「データ読み込み」を使ってください。まだ一度も書き出していない時や、最後の書き出しから14日たった時は、画面上部にお知らせが出ます。

## 開発者向け

- `js/t-data.js`：目標、期分化、トーン、種目、知識
- `js/t-content.js`：コメント用の文章、定型文、ラポール21日、課題サポート
- `js/t-engine.js`：期分化、記録の計算、注意、コメント・メッセージの作成
- `js/t-features.js`：返信アシスト、カウンセリング、食事・補食、サンプルデータ
- `js/t-app.js`：画面の操作
- テストはリポジトリ直下で `npm test`（`tests/training.test.js`）

## ご注意

表示される数値や情報は一般的な目安です。医療的な診断や治療に代わるものではありません。痛みや体調の異変がある時は練習を中止し、医療機関に相談してください。
